PCORI is funding AI/ML methods for CER — shared infrastructure still matters

PCORI’s methods portfolio increasingly includes AI/ML for patient-centered comparative clinical effectiveness research (CER). Funding advances science; shared open tooling helps labs execute reproducible analyses.

Research and education only. The EHR Risk Framework is not a medical device, is not FDA-cleared, and must not guide patient care. Posts summarize public sources for methods teaching—verify primary literature before citing.

What PCORI has emphasized

PCORI's Methods funding announcements list improving AI/ML methods in patient-centered CER among their program priorities. The precise portfolio changes by funding cycle, so this post does not treat a project count as a durable measure of the field.

See PCORI's Methods funding announcement and project database for current priorities and abstracts.

How the EHR Risk Framework helps

  • Standardized binary risk modeling loop for teaching and methods papers
  • Reproducible Docker + report artifacts
  • Transparency via SHAP (when run)
  • Room for subgroup / fairness jobs in the research stack

Not a PCORI-funded product claim—an open methods workbench aligned with reproducible CER practice.
