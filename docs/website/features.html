Dataset health gate

Before training, the API can report readiness blockers (too few patients, missing columns, etc.). The clinical_research persona can refuse forced training past blockers.

UI: Datasets → select → Run health → Continue to train when ready.

Feature engineering

  • Longitudinal multi-window features — prefixes w7d_, w30d_, w180d_ (configurable).
  • Index time strategies — last event or named column (task YAML).
  • Horizon labels — outcomes defined after the index, not mixed into past features.
  • Patient vs temporal splits — choose group-aware or time-aware evaluation.

Train & compare

Models

Logistic regression, random forest, XGBoost (optional LightGBM). Task presets under tasks/ (diabetes, heart_failure, readmission_30d, custom).

Compare job

Multi-model ranking by hold-out ROC-AUC with optional promote-best to the active artifact.

Named runs

Artifacts under reports/runs/ with manifests (data hash, params).

CLI

ehr-ai / python -m training.train for headless pipelines.

Angular workbench

Pages: Home, Datasets, Train, Results, Analytics, Config, Predict, Docs. Themes and density live in Config. See the annotated screenshot tour.

Serve & explain

  • GET /v1/model/schema — feature columns + optional input stats (medians)
  • POST /v1/predict — risk probability / level + optional SHAP explanation
  • Predict page — schema-driven form filled from medians
  • Results ZIP — metrics, audits, figures for sharing (demo data only in public repos)
